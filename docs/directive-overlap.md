# A signed freeze arriving during a Stratum submission

A worker obtains a same-parent job containing a stock-relayed signed payment. The lab computes a network-target solution, checks the complete candidate with the stock SV Node proposal RPC, and prepares a three-signer regtest freeze of the payment's exact input at the candidate's height. The proposal validates bytes without changing the reference tip. The first active-chain readback also checks that the stock block index has no candidate header.

The two controls serialize the freeze and solution end to end. The additional trials split the worker's actual Stratum request before its final newline. A second thread sends the alert gateway response on another loopback connection. A barrier releases both writers after each has flushed a prefix, with each complete frame still pending. All instrumentation uses one monotonic clock. In one trial the second writer is transferring the first health response reporting sequence 1. In the other the node has already discovered that sequence and the writer splits the signed-message response inside the signed frame's hex bytes. A known sequence gap can withdraw work before the complete signed record arrives.

The receipts record actual writer intervals, job acknowledgement, durably applied sequence, action receipt, local solved-block history, reference active hashes and the reference's independently mined successor. The stock reference receives its own freeze RPC after the entrant's durable application and the worker result. The timing measurements establish overlap across the two local sockets. The miner's state lock serializes application of the directive and the solution.

In the ordered controls, applying the freeze first left the reference on its old parent and produced zero local solved blocks. Delivering the solution first made its hash the stock active tip. The entrant's solution record then moved to the directive-retired state. The earlier stock active hash and recorded body delivery still establish adoption. Stock accepted each exact solved candidate as a proposal against the currently selected parent before publication. With the first reported sequence in flight, both writers had flushed a prefix and withheld a tail for 46,833 ns. With the signed frame itself in flight, that common interval was 17,708 ns. Both worker responses carried Stratum error 21 for stale work. Each entrant retained zero solutions, recorded the three-signer freeze at durable sequence 1, and observed a stock successor that extended the original parent.
