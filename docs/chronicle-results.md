## Validation and durable storage throughput

The host was an Apple M3 Max with 16 CPU cores and 128 GB RAM. Docker ran the Linux ARM64 release-profile test binary with the pinned native archive. Each measured body spent 4,096 distinct witnessed P2PKH outputs. All 16,384 signatures passed and every input value was known. Times include block parsing, hashing, BDK evaluation, witnessed-state update, undo and solution serialization, file sync, rename and directory sync. Fixture signing and network transit were outside the timer.

## Native publication and stale discoveries

In a single-peer regtest, Scary Node published two successive solutions and explicitly requested the stock SV Node’s active headers. It retrieved and validated both bodies while the reference still had no successor, 1,529 ms and 1,904 ms after each send. Each became active locally and reached settlement only after successors arrived. After restart, a delayed SV peer and a native Asset client each retrieved the 398-byte earlier solution. A signed invalidation then withdrew both that block and its descendant. These two delays measure this fixture. [Per-peer readbacks and exact wire bytes](evidence/chronicle-retained-delivery.json) · [Offline verifier](../qualification/verify_retained_delivery.py)

Sixteen fresh sizing sessions scheduled 512 tip races across the witnessed/full and full/full arms. In the witnessed/full arm, Scary Node was ready on 226 of 256 opportunities and the full miner on 256. Scary Node recorded 68 stale discoveries out of 145 (46.90%), and the full miner recorded 12 out of 191 (6.28%). The paired difference was +40.61 percentage points, with a session-clustered 95% interval of +28.72 to +52.51. The full/full control differed by +0.43 points (−12.77 to +13.64). The pilot serves to size the fresh evaluation. It called for **2,263 independent sessions, or 72,416 scheduled opportunities**, to target a one-percentage-point half-width. [Sizing summary](evidence/chronicle-native-sizing.json) · [Raw scheduled opportunities](evidence/chronicle-native-pilot)

Every sole discovery settled. Scary Node won 12 of 80 ties against the full miner. The full/full lanes split 85 ties 44 to 41. Among sole discoveries, the first observed active hash on either receiver took a median of 590 ms for Scary Node and 126 ms for the full miner. Both full/full lanes took about 125 ms. Stock SV Node and Scary Node used local native links, but the measured propagation times differed. These outcomes describe the engineering build's publication behavior and do not establish a stale-rate difference under equal end-to-end propagation. [Sole discoveries, ties and latency](evidence/chronicle-native-latency.json)

The SV publication loop on the measured build polled once each second for durable solutions. The revised build wakes each connected SV sender immediately after the solved bytes reach disk. Each sender rechecks parent, directives and readiness before emission. The counterbalanced comparison uses four fresh seeds on two otherwise identical binaries. Its receipt identifies each binary. The original evaluation continues on its frozen binary. [Run the comparison](production-cohort.md)

Losing the sole data connection now withdraws work immediately and retires the previous parent’s jobs. In regtest, SV Node advanced one block while disconnected. On reconnection, the entrant probed from its last contemporary header, received the missing body, and issued a job on the recovered parent. The reference selected that new solution. [Peer-loss receipt](evidence/chronicle-peer-loss.json)
