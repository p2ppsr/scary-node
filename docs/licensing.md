Ordinary script checks use the upstream Rust binding and native Bitcoin Development Kit archive built from its pinned SV Node sources. The BSV Rust SDK supplies transaction and cryptographic utilities. Rust libp2p supplies native peer transport. The reference Teranode containers run as separate processes. Cargo.lock pins Rust dependencies and the Compose file identifies the reference image. Refer to each upstream project for its own notices and license.
